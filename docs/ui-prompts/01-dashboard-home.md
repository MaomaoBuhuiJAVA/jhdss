# 首页(数据大屏)重构提示词

> 用法:将本提示词与首页参考效果图一起发给 AI,逐屏重构。本张对应「首页 / 数据大屏」。

## 角色与目标

你是前端工程师,负责重构 JHDS 智慧樱桃种植平台(Spring Boot + Thymeleaf + 原生 JS/CSS)的首页 `dashboard.html`。保持现有技术栈与后端接口不变,将首页重构为深色科技风的数字孪生监控大屏,以「中央大监控展示区」为绝对视觉核心。

## 视觉风格(严格参考附图效果图)

- 深色科技风:深蓝黑渐变背景(#05101f → #0a1a30),叠加网格/网点纹理
- 卡片:深蓝半透明玻璃拟态,1px 青色发光描边(rgba(0,229,255,.35)),圆角 10-12px,角部带发光切角装饰
- 主色:青色 #00e5ff;辅助蓝 #1890ff;强调橙黄 #ffb300;告警红 #ff4d4f;关键数据用大号发光数字
- 图标统一 Remix Icon(已走 CDN);标题文字带轻微青色发光
- 1920×1080 大屏优先,整页自适应,禁止出现纵向滚动条

## 页面结构

### 1. 顶部标题栏(替代现有左侧 sidenav)

- 顶部通栏,高约 64-72px
- 正中间:项目标题「智慧樱桃种植数字孪生平台」,发光字 + 两侧装饰线;右上角放实时时间(走秒)与天气小组件
- 标题左右两侧等分排列页面标签导航(胶囊样式,当前页高亮青色描边,hover 发光):
  - 左侧:首页、气象站、虫情监测、报警中心
  - 右侧:轨道巡检、物联控制、营养液、AI助手
  - 其余页面(AI学习、种植档案)收进最右侧「更多」下拉
- 导航做成 Thymeleaf fragment,路由沿用现有 `@{/dashboard}` 等

### 2. 中央监控展示区(视觉核心)

- 占屏宽 60% 以上、顶部栏以下高度的 65-70%,大号圆角发光面板
- 默认展示实时视频监控(沿用现有 flv.js / hls.js 直播流),右上角红色 LIVE 角标
- 左上角分段切换器:「实时视频 | 龙门架3D」
  - 实时视频:摄像头直播画面
  - 龙门架3D:Three.js(CDN 引入)程序化搭建的龙门架轨道巡检机器人数字孪生——龙门架主体、横向轨道、巡检小车、向下扫描的半透明光锥、网格地面,支持自动旋转与鼠标拖拽缩放
- 清晰度切换按钮:「超清 / 高清 / 标清」
  - 视频模式:切换对应码流地址
  - 3D 模式:切换渲染精度(像素比 / 阴影等级)
- 底部悬浮半透明工具条(鼠标移入浮现):播放/暂停、抓图、全屏、当前时间码
- 视频加载失败显示占位图 +「重新连接」按钮

### 3. 右上环境数据卡片(当前区域)

- 位于监控区右侧上方,宽约 18-20%
- 标题「当前区域环境」+ 区域下拉(如:温室1号)
- 指标纵向排列,每项含图标、名称、大号发光数值、单位、较昨日变化箭头:
  - 空气温度 ℃、空气湿度 %、CO2 ppm、光照 lux、土壤温度、土壤湿度
- 每 30s 轮询刷新,数值变化带淡入动画;超阈值时数值变橙/红并闪烁

### 4. 其余区域(保持简洁,可压缩)

- 右侧环境卡片下方:告警 / 农事简表滚动列表
- 底部通栏:48 小时环境趋势多折线图(ECharts,CDN 引入方式与 `archive.html` 一致)
- 空间不足时优先保证监控展示区尺寸,其余模块可压缩或省略

## 技术约束

- 仅改前端:`templates/dashboard.html`、`static/css/dashboard.css`、`static/js/dashboard.js`,公共样式 `common.css` 可微调;不改任何后端接口
- Three.js / ECharts / Remix Icon 统一走 jsdelivr CDN
- 视频流地址与环境数据接口沿用 `dashboard.js` 现有 fetch 逻辑,不新增后端依赖
- 兼容 Chrome / Edge 最新版

## 验收标准

1. 首屏即见居中大监控画面;左上角「实时视频 / 龙门架3D」秒切,3D 视图 ≥40fps
2. 清晰度按钮在两种视图下均有明确反馈
3. 顶部标题居中,两侧导航可跳转且当前页高亮
4. 右上环境卡片真实刷新、超阈值变色
5. 1920×1080 下无滚动条、无布局溢出
