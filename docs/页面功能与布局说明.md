# 页面功能与布局说明（用于生成效果图）

## 全局规范（每张图都适用）
- 画布：1920×1080，网页后台界面截图风格，非荧光深色控制台
- 背景 #12160f（墨绿黑），面板 #1a2018，描边 #2c362b
- 主色叶绿 #7cc491（柔和、不荧光），告警红 #e5564b，警示麦金 #d9a84e，数据蓝 #6fa8c9
- 文字：主文字 #eef3ea，次要 #b6c2b2，弱化 #84927f；数字用等宽字体（Bahnschrift/Consolas 风格）
- 字号偏大（投屏场景）：页面标题 18px+、卡片标题 16px+、正文 15px、关键数字 26px+
- 无渐变霓虹、无玻璃拟态、无发光文字；卡片为纯色细描边

## 全局框架（每页都有）
- 左侧固定导航栏，宽 220px：
  - 顶部品牌区：樱桃红圆角方块图标（幼苗图案）+「智慧樱桃种植」+ 英文小字 CHERRY FIELD STATION
  - 分组导航（组名小字浅灰，项高 44px，图标+文字，选中项左侧 3px 叶绿竖条+淡绿底）：
    - 总览：数据大屏
    - 监测：气象站 / 虫情灯 / 报警中心
    - 控制：AI 轨道巡检 / 物联设备 / 营养液配液
    - 智能·档案：AI 农业助手 / AI 学习 / 历年档案
  - 底部：绿色状态点「系统运行中」+ 版本小字 JHDS PLATFORM · V3
- 顶部栏高 56px：左侧当前页面标题（粗体 18px），右侧绿点+实时时钟（等宽数字）
