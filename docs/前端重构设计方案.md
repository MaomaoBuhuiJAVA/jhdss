### 1.2 现有 UI 的核心问题

1. **视觉**：深黑底 + 荧光绿 + 发光边框 + 扫描线，是典型「科技大屏模板」，与农业生产场景脱节
2. **无信息层级**：所有模块都是同一种卡片，满屏小卡片，重要信息（视频、告警、待办）与次要信息（市场反馈）权重相同
3. **导航拥挤**：顶部 10 项平铺无分组，1920px 下已捉襟见肘
4. **空间数据被浪费**：系统里已有大量空间语义（种植架 1-4、告警位置「3号种植区 C1」、巡检轨道位置「A/B区」、虫情灯「东区/西区」），却没有任何空间表达
5. **种植架 1-4 tab 是静态摆设**，无数据绑定，误导用户
6. **数据展示与数据类型错配**：12 个气象传感器、8 个土壤指标同权重平铺；6 条曲线混排一张图
7. **大量内联 style** 写在 HTML 里，样式不可维护
8. **AI 悬浮球**每页重复、遮挡右下角内容
9. **图表荧光配色**（#00ffaa/#1890ff/#f5c842/#c084fc）与农业场景气质不符

## 二、设计方向：「畦 · Fieldbook」

**一句话：不是监控大屏，而是樱桃园的数字化工作台账 + 控制中心。**

参考系：John Deere Operations Center、Climate FieldView、专业气象业务平台、水肥一体化控制柜 HMI、工程图纸。
三条设计原则：

1. **数据有出处** —— 每个读数标注来源、时间、单位；宁可少展示，不展示无意义数据
2. **操作有确认** —— 控制类操作（电机/泵/开关）有明确状态反馈与回执，保留语音播报
3. **空间有位置** —— 用棚区平面图承载一切「在哪」的信息

**反 AI 模板纪律**：无蓝紫渐变、无霓虹发光、无玻璃拟态、无巨大数字卡、无装饰性动画。

## 五、布局与导航

- **顶部 10 项平铺导航 → 左侧固定导航栏**（208px，可收起为 56px 图标栏），四组：
  - 总览：数据大屏
  - 监测：气象站 / 虫情灯 / 报警中心（带未处理数徽标）
  - 控制：AI 轨道巡检 / 物联设备 / 营养液配液
  - 智能·档案：AI 农业助手 / AI 学习 / 历年档案
- 当前页：左侧 3px 墨绿指示条 + 浅绿底 + 加粗
- 侧栏底部：全局连接状态（MQTT / 摄像头 / 气象站心跳）+ 版本
- **顶栏精简为**：温室名 + 当前页 / 控制面板连接状态 / 时钟
- **取消 AI 悬浮球**（导航已有入口），不再遮挡内容

## 六、首页（数据大屏 → 温室总览）结构

进入页面后第一优先级：**棚的状态是否正常 → 现场画面 → 今天该干什么**。

1. **状态带**（非巨大数字卡，一条 64px 信息带）：棚名/作物/生育阶段徽章 + 温/湿/风/光照四个读数 + 设备在线 x/y + 未处理告警 pill
2. **中央：棚区平面图**（核心视觉，见第七节）
3. **左列：主监控视频**（深舱框、取景角标、LIVE 徽标、缩放/声音工具条）+ 次监控缩略 + 气象四项缩略
4. **中下：环境趋势 48h**（温度主线 + 湿度副线、昼夜底纹、坐标轴完整）
5. **右列**：告警信息（级别色条 + 位置 + 状态标签，点击展开详情）→ 农事记录（纵向时间轴）→ 待办农事（沉底、可执行）→ 市场反馈
6. 原「种植架 1-4 假 tab」移除，由平面图的可点击种植架替代

## 七、地图设计（诚实版：棚区平面图纸）

系统**没有 GIS 坐标数据，不伪造地图**。用「棚区平面示意图」承担空间可视化——工程图纸风格的 SVG 俯视图：

- 图纸要素：方格纸底、尺寸标注线、指北针、比例尺、图签栏（图号 JHDS-PLAN-01）
- 空间对象：种植架 1-4（可点击、选中态）、巡检轨道 RAIL-01 与摄像头滑车当前位置（CAM-01 · B区）、环境传感器节点、土壤传感器、东/西虫情灯、A/B/C 分区
- **告警定位**：C1 区域红色虚线框 + 慢速呼吸晕（唯一允许的循环动画），点击 → 告警详情弹窗
- 点击种植架 → 浮签显示该架作物/株数/土壤湿度 EC/最近操作
- 数据来源全部为现有字段（location、trackPosition、设备分组、种植架配置），纯前端新增组件，**不改任何后端接口**
- 未来若有真实地块坐标，可平滑升级为 WebGIS

## 九、组件规范

- **卡片三种材质**：白纸卡（数据）、图纸卡（平面图，方格底）、深舱卡（视频/操控台）。统一 1px 暖灰边 + 微弱投影，无发光无玻璃
- **按钮四级**：墨绿实心（主操作）/ 墨绿描边（次操作）/ 文字（弱操作）/ 樱桃红（停止/危险）
- **开关**：控制柜拨杆质感，开启态墨绿
- **卡头规范**：衬线标题 + 英文大写小标签 + 右侧操作链接
- **状态点**：7px 圆点 + 柔和外环（非发光）
- **弹窗两级**：居中模态（详情/表单）+ 右侧抽屉（阈值设置等配置类）
- **空态/骨架屏**：统一线稿图标 + 一句人话
- 时间轴、表格、表单、Toast、徽标：按纸面台账风格统一

## 十一、交互逻辑

- **平面图钻取**：点种植架 → 浮签详情；点告警区 → 告警弹窗；点摄像头 → 定位到视频
- **告警行**整条可展开（描述/处理记录/状态流转）
- **控制类操作**：点击 → 保存中 → 成功/回滚，全程有状态文字，保留讯飞语音播报
- **视频工具条**：悬浮自动隐藏，鼠标移入出现
- 保留全部现有快捷键与无障碍属性（aria-*、键盘可达）
- 新增交互均为纯前端附加，失败时不影响原有功能

## 十二、动效策略（克制）

- 页面入场：卡片 120-260ms 交错浮起（≤8px 位移 + 透明度）
- hover：卡片抬升 1-2px + 阴影加深；按钮 180ms 过渡
- 开关/进度/抽屉：200-260ms ease-out
- **唯一循环动画**：平面图告警点 4s 慢速呼吸、视频 LIVE 录制点
- 巡检扫描线、AI 扫描动画：属功能反馈，保留
- prefers-reduced-motion：全部关闭
- 删除：背景漂移、发光脉冲、装饰性粒子

## 十三、技术约束与实施步骤

**不改的**：
- 后端零改动；所有 /jhds/api/** 接口、数据结构、SSE 通道原样使用
- JS 业务逻辑（视频看门狗、flv/hls 回退、PTZ、双电机、自动巡检、语音播报）不重构，仅允许两类 JS 改动：① 图表颜色常量换新色板 ② 纯新增的平面图组件脚本
- 全部 DOM 钩子（id / JS 查询的 class / data-* / 内联 onclick 函数名）原样保留，清单见 preview/contracts.json

**实施顺序**（每步产出截图验证）：
1. 设计系统落地：重写 common.css（令牌/导航/卡片/按钮/表单/弹窗）+ header fragment → 左侧导航布局
2. 数据大屏（含平面图组件）
3. AI 轨道巡检（最复杂，深舱控制台）
4. 气象站 + 营养液配液
5. 虫情灯 + 报警中心
6. 物联设备 + AI 助手 + AI 学习 + 历年档案
7. 图表配色统一、动效收尾、prefers-reduced-motion、全页面回归截图

**验证方式**：preview 静态预览（mock.js 拦截 API）+ Playwright 截图逐页核对；构建启动后端做真实回归。
