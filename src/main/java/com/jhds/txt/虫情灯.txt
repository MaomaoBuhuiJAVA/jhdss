# 接口文档

## API Docs
- 轻量物联网接口 [登录认证](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203165e0.md): 根据注册的用户名和密码(需要MD5加密传输,加密格式为32位小）进行登录获取token （token过期失效时间7天）
- 轻量物联网接口 [获取设备列表](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203166e0.md): 通过设备类型和登录获取的token来获取设备列表;
- 轻量物联网接口 [获取设备实时数据](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203167e0.md): 通过设备编号和登录获取的token来获取设备信息;
- 轻量物联网接口 [获取设备数据历史记录](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290209443e0.md): 
- 轻量物联网接口 [获取最新设备控制状态（不包括视频监控）](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203168e0.md): 通过设备编号来获取设备现在控制的状态
- 轻量物联网接口 [获取控制参数](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203169e0.md): 通过设备编号和token来获取对应的控制参数
- 轻量物联网接口 [发送控制命令](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203170e0.md): 发送之前需要通过获取控制参数接口获取对应的数据;
- 轻量物联网接口 [获取最新的(虫情、孢子)照片](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203171e0.md): 通过设备id和token来获取最新的(虫情、孢子)设备拍摄照片
- 轻量物联网接口 [虫情图片历史记录](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203172e0.md): 通过设备id和token来获取虫情图片历史记录
- 轻量物联网接口 [获取流量卡数据](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203173e0.md): 获取当前用户下的流量卡数据
- 轻量物联网接口 [获取设备状态预警/数据异常预警/流量到期预警接口](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/290203175e0.md): 获取设备状态预警/数据异常预警/流量到期预警接口
- 轻量物联网接口 [获取性诱设备历史数据](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/385363809e0.md): 
- 轻量物联网接口 [球阀控制](https://s.apifox.cn/4c6a02fb-384e-43ae-96b6-076003ca135f/405591379e0.md): 电动球阀-三通/电动球阀-直通/电动蝶阀通用接口
